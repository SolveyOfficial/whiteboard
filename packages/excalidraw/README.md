# Editor package

The drawing editor used by Solvey Whiteboard. It is based on the [Excalidraw](https://github.com/excalidraw/excalidraw) editor (`@excalidraw/excalidraw`, MIT licence), adapted to work fully offline: fonts are served by the app itself and the features that rely on Excalidraw's online services are removed or switched off.

See the [main README](../../README.md) for how to run and build the app.
